# Expense Chart - Учет расходов с построением графиков

## Автор
**Торгунакова Виктория**

## Краткое описание
**Expense Chart** - это консольное приложение для учета личных финансов, позволяющее добавлять, просматривать, фильтровать расходы и строить наглядные графики распределения расходов по категориям с использованием библиотеки matplotlib.

### Основные возможности
- ✅ Добавление расходов с указанием суммы, категории и даты
- ✅ Просмотр всех расходов в табличном формате
- ✅ Фильтрация расходов по категории и периоду
- ✅ Подсчет суммы расходов за выбранный период
- ✅ Статистика по категориям с процентным соотношением
- ✅ Построение столбчатых диаграмм расходов по категориям
- ✅ Сохранение и загрузка данных в JSON
- ✅ Валидация ввода (отрицательные суммы, формат даты)
- ✅ Инкапсуляция и наследование в ООП
- ✅ Графики сохраняются как PNG файлы

### Технологии
- Python 3.7+
- Matplotlib - построение графиков
- JSON - хранение данных
- Datetime - работа с датами
